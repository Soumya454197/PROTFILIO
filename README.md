## 🚀 Getting Started

Clone the repo and open locally:

```bash
git clone https://github.com/Soumya454197/PROTFILIO.git
cd PROTFILIO
```

Open `index.html` directly in your browser, or serve it locally:

```bash
npx serve .
```
